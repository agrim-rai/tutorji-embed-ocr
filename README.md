# Tutorji - Interactive Learning Assistant

⚠️ **This project is currently under development and not ready for production use.**

A Next.js application that provides step-by-step analysis and interactive learning for educational content using AI.

## Getting Started

1. **Clone the repository**
```bash
git clone <repository-url>
cd tutorji
```

2. **Install dependencies**
```bash
npm install
```

3. **Set up environment variables**
   - Create a `.env.local` file in the root directory
   - Add your API keys and configuration (see environment setup documentation)

4. **Run the development server**
```bash
npm run dev
```

5. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000)

## Technology Stack

- **Frontend**: Next.js 14, React, TypeScript, Tailwind CSS
- **Backend**: Next.js API Routes, MongoDB
- **Authentication**: NextAuth.js
- **AI/ML**: OpenAI API
- **Image Storage**: Cloudinary
